# 决策模板

> **状态 Status:** canonical（持久决策的当前模板入口）
>
> **目的 Purpose:** 为真正约束后续维护的判断提供最小而完整的记录结构。
>
> **参见 See also:** [决策记录模板](decision-record.md)、[决策记录](../README.md)。

当一个判断需要约束后续维护、定义边界或保留复审条件时，使用
[决策记录模板](decision-record.md)。普通工作笔记、临时讨论和未验证设想不应伪装成持久决策。

DR 只记录持久取舍，不承载 OpenSpec 任务、实施步骤、原始命令输出或验收流水：变更属于
OpenSpec，已验证观察属于 Chronicle，团队规则属于 `guidelines.md`。
