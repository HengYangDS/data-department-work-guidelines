# 决策：准则读者体验重构

> **状态**：已接受

## 问题

`guidelines.md` 是准则正文的唯一事实源，但完整正文不适合作为每位
读者的首次加载路径。此前读者需要自行从长正文辨认场景、入口与下一步，
容易跳过底线、责任边界或验真要求；Agent 也需要在不复制规则的前提下，
得到足以开始任务的最小路由。

本次问题的证据是正文已经具备完整的原则、深度规则与模板，却缺少将首次
阅读、场景选择和深读入口连成一条可检验路径的结构。此问题关乎文档可读性
与结构质量，不是对团队运行结果的判断。

## 决定

保留 `guidelines.md` 为唯一规则事实源，将阅读体验组织为
“三分钟定向—场景路由—深度规则”：

- `README.md` 提供人类读者的四条底线与六个场景入口；
- `AGENTS.md` 提供 Agent 的最小加载顺序、任务路由与修改约束；
- `guidelines.md` 提供任务内核卡、六张场景行动卡、五张可渲染 Mermaid
  图、深度规则、模板与验真；
- 文档质量门检查 Markdown、链接、锚点、唯一规则事实源的关键契约与五张图；
- 变更仅在 Task 4 验证命令全部通过、默认 SVG 与 768px 宽 PNG 均经检查后
  被接受。

## 验证证据

接受检查要求：`./scripts/validate-docs.sh --render-dir /tmp/data-guidelines-qa`、
`markdownlint-cli2 '**/*.md' '#.superpowers/**'`、`git diff --check HEAD` 均须
退出 0，且 `rg -n '```mermaid' guidelines.md | wc -l` 须输出 `5`。五张图的
默认 SVG 与 768px 宽 PNG 必须逐张确认：标签未裁切、语义边无不必要交叉、
起始状态明确，且状态不依赖颜色表达。

## 不作的主张

本次接受只证明文档在当前版本具备可验证的入口、链接、结构与图形质量。
不主张成员已改变阅读或工作行为，不主张协作质量、交付质量或团队质量已经
提高；这些结果仍须由真实试点、运行证据与后续复审验证。

## 复审触发

出现下列任一信号时，重新评估本决定：

- 读者在首次路径中仍无法找到当前场景的下一步，或入口链接、锚点失效；
- 入口文件开始复制、改写或与 `guidelines.md` 冲突；
- 图在默认或窄宽渲染中出现裁切、含混起点、无必要交叉或颜色依赖；
- 新增、修订或废止规则的维护成本超过可观察的净增益；
- 真实试点表明场景卡、模板、停止条件或验真入口不足以支持正确行动。
