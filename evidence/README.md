# 持久证据根

本目录是 ETHOS 的持久证据根；它不是临时日志目录，也不替代 `docs/evidence/` 的读者导航。

| 位置                         | 作用                 | 进入仓库事实的条件                 |
| ---------------------------- | -------------------- | ---------------------------------- |
| `claims/`                    | 机器可读的主张与绑定 | 主张范围、证据、验证者和限制明确。 |
| `chronicle/<主题>/<日期>.md` | 可审阅的事实记录     | 主题、时间、对象与限制清楚。       |
| `parity/`                    | 外部投影的一致性材料 | 仅在实际获得相应外部证据后写入。   |

可再生产物应留在 `build/evidence/` 或 `build/ethos/`；本机缓存、租约与运行状态应留在
`.ethos/state/` 或其他被忽略的运行位置。
