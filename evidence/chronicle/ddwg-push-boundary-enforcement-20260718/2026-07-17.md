# DDWG remote candidate push boundary — 2026-07-17

## Claim

The repository's local pre-push boundary will reject `candidate/dev` before it
can enter either GitLab or GitHub projection, while retaining ETHOS admission
for eligible refs.

## Boundary

This claim is about local hook behavior only. It excludes provider branch
protection, authentication, remote push success, hosted CI, and changes to the
normative `guidelines.md`.

## Evidence

- A direct hook simulation previously returned success for candidate projection.
- The existing governance specification already states that `candidate/dev` is
  local-only.
- This Change adds a portable offline regression and makes it a local proof gate.

## Decision

Fail closed at the repository hook boundary, then re-prove and close out locally
before separately probing or publishing either provider plane.
