# Chronicle: CI checkout runtime repair — 2026-07-18

## Observation

A GitHub hosted documentation run for the accepted governance repair failed
before document verification because the job-level `node:22-bookworm` container
did not provide Git to `actions/checkout`. Checkout fell back to an archive, and
the repository verifier correctly rejected the absence of a Git checkout.

## Action

This active Change removes the GitHub job container, performs checkout on the
GitHub-hosted runner, selects Node 22 explicitly after checkout, and requires
Git in GitLab's Docker prerequisites. Both providers continue to call the same
repository-owned verifier. The repository regression test checks the projection
contract without treating local parsing as a hosted result.
