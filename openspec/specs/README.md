# OpenSpec Capability Specs

Each capability directory contains accepted behavior in `spec.md`. Capability
paths name cohesive, durable behavior, not packages or implementation tasks.
Under **Modified Capabilities**, a proposal names the exact existing path under
`openspec/specs/`. **New Capabilities** may introduce a new cohesive path through
the official Change's deltas. Follow the official artifact fields and directory
shape; repository-private metadata does not extend them.
