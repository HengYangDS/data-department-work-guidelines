# OpenSpec Workspace

This workspace is the ETHOS case and specification carrier. Use
`./scripts/ethos-repo.sh ...` as the repository-governance workflow; use the
official `openspec validate --all --strict --json` command when specification
health must be proved.

Cases are active changes under `openspec/changes/<change-id>/` with proposal,
design, tasks, spec deltas, claim binding, and evidence refs. Accepted behavior
lives under `openspec/specs/<capability>/spec.md` after promotion.
