# Proposal

## Why

The shorter English topics need a complete comparison with the last unified
guideline, not another assurance based on their length or earlier review. A
fresh read found omitted qualifiers in change control, Agent reporting, and
management responsibility.

## What Changes

- Record the comparison of every former section and its important adverse cases
  in this Change's design, using the exact former Git blob.
- Restore missing qualifiers at the existing normative topic owners: record
  scope decisions, expose incomplete work, preserve qualified professional
  judgment, and make management's example and timely decisions explicit.
- Clarify review language so meeting acceptance criteria does not imply that an
  executor has authority to accept their own work.
- Keep the current task routes and the event, monthly, and quarterly feedback
  floor. Retain useful meaning from former forms in their task owners.
- Verify the source, accept it through ETHOS, and publish a patch edition with
  the same source and offline tool bundle on both Forges.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. These corrections implement the existing `guidance-discovery`
requirements for semantic coverage, unique normative ownership, and feedback.
The official Change sets `skip_specs: true`; no new spec behavior is invented.

## Impact

Affected topics are `docs/charter.md`, `docs/deliver.md`,
`docs/human-agent.md`, and `docs/evolve.md`. The source-to-owner review also
covers `docs/decide.md`, `docs/data.md`, `docs/communicate.md`, and the task map.
The release phase updates the version, Changelog, charter edition, and existing
offline bundle manifest. There is no dependency, command, or navigation change.
This work does not certify team adoption or change the ETHOS product.
