## Why

The guidelines state the value of data work twice, and the two statements disagree. The README says
signals become "judgments and data assets that can be explained, checked, and used within clear
limits"; the charter says "reliable judgments, data assets, and actions". The README leaves out
actions, and its last property, "used", does not fit an action. The films' steward asked which
products the three properties belong to (entry 12 of the films' ledger).

## What Changes

- The README names all three products, as the charter does, and gives each the three properties:
  judgments, data assets, and actions that can be explained, checked, and relied on within clear
  limits. "Relied on" fits all three and states what the charter's "reliable" means.
- The 9.0.0 Changelog records the correction.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. The correction keeps the accepted requirements and uses the official no-spec marker.

## Impact

The README's opening sentence and the 9.0.0 Changelog; still 9.0.0.
