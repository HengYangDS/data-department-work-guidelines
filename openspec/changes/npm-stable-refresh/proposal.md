# Proposal

## Why

npm 12.2.0 became the official stable release while v6.0.0 was being qualified.
It supports the declared Node 26 runtime. Update the actual native package
manager without rewriting the published signed release or forcing dependencies
outside their upstream contracts.

## What Changes

- Advance the single native npm declaration from 12.1.0 to 12.2.0.
- Retain fail-closed version admission, explicit ephemeral acquisition, and
  maintained native account ownership.
- Rebuild source-bound offline supply and qualify source and real offline
  installation on both Forges before releasing a compatible patch edition.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `quality`: consume the new stable package-manager release through the existing
  native contract and actual execution boundary.

## Impact

The native package manifest, matching negative tests, release identity, and
offline supply change. Department rules, reader routes, repository dependency
pins, upstream-constrained transitives, credentials, and governance authority
remain unchanged. v6.0.0 remains immutable.
