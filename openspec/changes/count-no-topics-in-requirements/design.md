## Context

See proposal.md. `.ethos/profile.toml` declares the normative sources; a count in a requirement is a
second copy of that list's length.

## Goals / Non-Goals

**Goals:**

- One source for which topics exist: the declared normative sources.

**Non-Goals:**

- Any change to what the requirements require of each topic.

## Decisions

- **No number.** "Every topic" and "department topics" cover the new page and any later one without
  another edit.
- **Retired-guideline scenario.** It compares the retired text with the topics that replaced it, so
  it names those, not every current topic.

## Risks / Trade-offs

- [A reader expects a count] → The documentation map lists the topics.
