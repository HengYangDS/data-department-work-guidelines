# Spec Delta

## REMOVED Requirements

**Reason:** The repository retires its Node maintenance toolkit: the private package and lock, the
OSV Scanner supply and audit, the offline bundle with its builder, acquisition and workflows, and
the code and tests that served them. Installed ETHOS owns the shared checks and its own supply,
and reading needs no installation.

**Migration:** Three duties remain and move: reading without installation to
`guidance-discovery`, source-event tag routes to `publication`, and command and CI-name currency
to `verification`. Hosted jobs install ETHOS through Mise; `publication` states GitLab's Mise
bootstrap. Earlier editions keep their signed tags, notes and attached downloads under the
unchanged retention requirement. With `retire_capabilities: true`, archive deletes this
capability.

### Requirement: Tool supply and portability require executed checks

### Requirement: A supplied offline bundle can install the complete verification toolchain

### Requirement: The actual package manager conforms before execution

### Requirement: Package-manager acquisition stays outside offline verification

### Requirement: Public bundle acquisition has no ambient CLI dependency

### Requirement: Complete retirement of replaced quality tools

### Requirement: One source-bound native quality supply

### Requirement: Source-event tag routes match the release family

### Requirement: Current commands and CI names remain executable

### Requirement: Reading guidance is independent of tool installation
