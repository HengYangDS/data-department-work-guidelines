# 数据部门工作与人智协作准则

> 先求其真，使其可达；再令其有序，使其可行。

## 三分钟定向

| 先记住                                          | 含义                             |
| ----------------------------------------------- | -------------------------------- |
| [不欺真](./guidelines.md#23-四条不可突破的底线) | 让事实与证据校正判断。           |
| [不越界](./guidelines.md#23-四条不可突破的底线) | 让权限、风险与对象边界清楚可见。 |
| [不悬责](./guidelines.md#23-四条不可突破的底线) | 让判断、决定与验收有明确归属。   |
| [不伪成](./guidelines.md#23-四条不可突破的底线) | 让完成主张与新鲜验证相称。       |

## 权威与演化

- [`guidelines.md`](./guidelines.md) 是唯一规则事实源。
- [`AGENTS.md`](./AGENTS.md) 是 Agent 读取路由。
- [`CHANGELOG.md`](./CHANGELOG.md) 记录生效变更。
- [`docs/decisions/`](./docs/decisions/) 与 [`docs/retrospectives/`](./docs/retrospectives/)
  保存取舍和经验，不重写规则。
- [`docs/adoption/`](./docs/adoption/) 是真实试用与项目接入的准备包，不构成规则副本。
