# Data Department Work Guidelines

We turn signals from the world into judgments, data assets, and actions that
can be explained, checked, and relied on within clear limits. These guidelines
help us tell apart facts, responsibility, action, and evidence. They do not
require every task to fill out the same form.

**Start with your work question:** the [documentation map](docs/README.md)
leads to the applicable rule and its limits. You do not need to read every
topic first.

The same care applies to expression: you must write with [fidelity, clarity, and
elegance](docs/communicate.md#write-for-fidelity-clarity-and-elegance).

This is a documentation repository. Members and Agents can read and use the
guidelines without installing software.

To change this repository, read [Contributing](CONTRIBUTING.md); Agents start
at the [Agent entry](AGENTS.md). Document checks, source acceptance, remote
publication, and actual team use are different facts and require different
evidence.
