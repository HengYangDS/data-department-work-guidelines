# 数据部门工作与人—Agent 协作准则

本项目维护数据部门通用工作质量及人—Agent 协作准则。

## 权威入口

- [guidelines.md](./guidelines.md)：团队成员与 Agent 共同遵循的唯一准则正文。
- [AGENTS.md](./AGENTS.md)：Agent 进入本项目时的最小读取与修改约束。

## 使用方式

1. 团队成员按 `guidelines.md` 的“如何使用本准则”及场景入口读取相关章节。
2. 各业务或工程项目可以补充局部事实源、权限、流程和验收要求，但应引用本项目，不复制通用准则。
3. 对正文的修订应说明所针对的真实问题、预期净增益、验证方式和复审时点。

本项目只维护通用工作质量契约；岗位职责、项目事实、业务语义和工程实现仍由各自权威项目维护。
